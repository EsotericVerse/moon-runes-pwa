治理

治理處理 LOC 與月之符文如何被使用、引用、延伸與修正。這裡先保留四個入口：原則、版權、理念與文件。

Principles

原則

去神格化、中立、不道德綁架。

月之符文保留符文、抽籤與籤詩的文化與創作形式，但 LOC 不預設超自然力量、神授權威或唯一正解，也不替使用者判定信仰、人生觀或價值選擇的正確性。

系統可以分析語言、語意、脈絡、關係與可能性，但分析不是命令；不得把多數意見、社會期待、道德壓力或情緒施壓升格成使用者必須服從的答案。

承載既有經驗，導入新的方法，面對新的情境。

既有經驗不因方法更新而失效；新方法也不必被舊有框架綁住。LOC 保留已發生的資料與歷史位置，在新的條件下重新分析、校準與推演。

這項原則源自作者早期「第二宗教／斜槓教」的思想實驗：不要求人否定原有信仰、文化或生命經驗，而是在既有基礎上加入自己選擇的新方法。進入 LOC 後，宗教語境被抽離，留下可客觀使用的治理結構：保留來源、允許更新、尊重主體、方法可替換、結論可再檢驗。

因此，LOC 不以新版本抹除舊版本，也不因歷史存在就把舊定義視為永久真理。事件與來源應保留；定義、方法與解釋可以隨證據與需求校準。

Spec 優先。 高歧義或容易被一般字面直覺帶偏的符文，必須先以 Spec 明確界定它描述的主體，再進入關鍵詞、方向與延伸描述。Spec 是語意邊界，不是事後補充。

先判斷詞彙本身的詞性，再判斷群組的主體性。 RAG 的基礎分類先辨認詞彙在文本中的實際詞性，例如名詞、動詞、形容詞或副詞；再依 LunaRunes 群組所代表的語意場域與主體性，判斷應歸屬的符文。不得只憑字面關鍵詞直接映射。

優先使用不需 API key 的可解釋分類。 能以固定資料、詞性、群組主體性、關鍵詞與規則完成的基礎分類，先在本地完成，再進行統計、索引與關聯；只有規則不足以有效區分時，才進入更高階的語意分析。

先治理，再實作。 語意定義、分類規則與文字呈現原則先確定，再套用到資料、RAG、介面與功能頁；避免因實作先行而讓舊定義、暫時文字或不同頁面的例外回寫成新的語意污染。

理念

政德風是王政德的個人綜合 IP 風格；治理只是其中一個面向。

政德風的治理理念以校準與治理為核心：先辨認語意、位置、權責與邊界，再決定保留、修正、分流或留下歷史。治理不是把目前版本變成永恆答案，而是讓改變有來源、有脈絡、有邊界，也能被再次檢視。

LOC 的客觀化核心不是要求接受作者的信仰，而是把可重複使用的方法留下。 對既有資料先承載而不抹除；對新問題允許導入新方法；面對新的時間、脈絡與條件，再重新判斷。

可以把過去當資料，但不把過去當枷鎖；可以修正現在，但不必抹除曾經存在的版本。
