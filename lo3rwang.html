Zhengde Style · Current

政德風

政德風是一種從創作、推演、校對與治理逐漸形成的個人風格。它不追求全知或絕對正確，而是在建立定義與規則之後，持續接受反例、誤判與新的可能；可以分析趨勢，但不讓趨勢代替人的選擇；可以建立系統，也同時要求系統知道自己的邊界。

在創作上，政德風允許荒誕、幻想與黑色幽默，但重視設定成立之後的因果一致性：想像力可以打開可能，後續發展仍需要對人物、世界與既有條件負責。

在方法上，常見的思考軌跡是：定義 → 公理 → 推論 → 反例 → 校對 → 應用。推演用來展開可能，而不是製造唯一答案；錯誤不必被抹除，也可能成為下一次理解與修正的起點。

在治理上，政德風重視來源、脈絡、邊界與人的自主性：理解不等於裁定，影響不等於擁有，相似不等於相同，推演不等於結果。

這些特質並非一次完成，而是在不同時期的小說、歌曲、文字與系統創作中逐漸形成。完整的形成軌跡、作品來源與觀念演變，另由治理與文化脈絡保存。

Professional Focus

我主要在做什麼？

工作核心不是單純產出內容，而是處理語言、資料、脈絡與時間之間的關係。常見問題包括命名與正名、語意污染、資料分類、知識架構、搜尋與 RAG、版本治理、文本關係、長期演化，以及既有系統中不同來源與不同時期資料如何共存。

我的做法通常不是把既有個案套進 LOC，而是先理解對方原本的語言與資料，再依需求建立適合自己的結構、規則與實作方式。

Systems · Creation

LOC、LunaRunes 與創作

LOC／月典是一套可重複使用的 Language Module Framework／語言模組框架，用來分析、組織、搜尋、治理並推演語言與資料。

LunaRunes／月之符文是具有獨立 Master Data 與治理權威的 Symbolic Language Module／符號式語言模組。它從早期字卡與敘事玩法逐步演化成目前的 66 符文系統；完整演化脈絡由 LunaRunes Scope 保存，不堆在作者頁。

其他公開創作包含歌曲與歌詞、小說與文字作品、多媒體、政德風，以及長期的生活文字與語言治理紀錄。
