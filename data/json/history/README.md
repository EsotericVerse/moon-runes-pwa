# History data boundary

History in this directory is evidence/reference, not Current authority.

- Current governance determines present definitions.
- Historical facts are preserved and may be reinterpreted in later context.
- Historical records must not expose retired aliases, fallback mappings, authority mappings, or classification rules as reusable Current definitions.
- Historical events should reference stable `entity_id` values and use `occurred_at` / `recorded_at` timestamps.
- Unknown event time remains `null`; do not invent timestamps.
