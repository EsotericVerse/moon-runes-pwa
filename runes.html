符文分類

Canonical Definition

現行符文本義、編號、群組、固定月相與 Canon 欄位是分類基準；歷史資料不得覆寫現行定義。

Generation Record

創作前抽出的符文是生成條件，可以與作品中的實際語意命中分開記錄；兩者都能成為統計證據。

Narrative Occurrence

正文中真正出現、被使用或經語意分析判定的符文另行記錄，不由生成牌序反推。

Group Projection

符文命中可直接投影回八大群組與特殊符文，供群組統計、關係分析與推演使用。

符文演算法

Deterministic first

符文 ID、名稱、群組、tags、hashtags、抽牌 cards 等結構化資料優先直接計算，不需要 API key。

Grammar

單卡、雙卡、三卡、五卡與 OW3gs 各自有固定卡位責任；位置結構與方向先於自由解讀。

Semantic classification

自由文本可進一步判斷符文語意，形成作品與符文之間的衍生關係，但不能取代 Canon。

Governed write-back

分析結果若經驗證與治理確認，可以寫回新的結構化狀態，供後續統計與推演使用。

延伸體系

符文脈絡

兩個以上符文、事件或作品產生關係時形成脈絡，重點是彼此如何連結以及在什麼情境成立。

符文歌曲

實際抽牌、符文語意、曲風 metadata 與作品可形成可搜尋、可統計的音樂延伸資料。

符文文學

符文可延伸到角色、情境、事件、章節與文本語意；生成牌序與正文命中可以同時保留。

符文演化

將分類、關係、演算法與知識模組放回時間，觀察語意偏移、頻率變化與結構演化。
