怎麼玩

Event Phase

  1. 翻開事件卡。
  2. 每位玩家打出三張符文。
  3. Alpha 先以 SL／ML／NE／OC 組態覆蓋作快速判定。
  4. 每位玩家擇一：自我共振（De +1）、破壞性共振（指定玩家 De −2）、或使用符文技能。
  5. 固定 De +2，再依事件結果扣除代價。
  6. 補牌至五張。

RP / 16★ / 0′

RP：不翻事件、不打三張符文，每位玩家進行一次互動。

16★：De 首次達 16 後得到勝利資格，但不是立即勝利；必須在下一次 RP 後仍維持。

0′ RP：八相循環完成後，不重置歷史與狀態，進行最後一次重新定錨。

覆蓋名稱代價淨變化
4/4完美0+2
3/4成功−1+1
2/4普通−20
1/4補牌−20；抽2棄1
0/4失敗−4−2
四大組態覆蓋是 Alpha 的快速判定層，不是最終語義引擎。現行方向是逐步把雙卡因果、三卡源－轉－合，以及五卡、十一卡的多卡規律真正帶入事件判定。
