# NAV Scope data boundary

`context`, `statics`, `evolution`, `governance`, and `search` are shared function names. A NAV link never changes the active Scope unless it is an explicit cross-Scope role/home link.

Therefore LunaRunes NAV functions remain LunaRunes-scoped, lo3rwang NAV functions remain lo3rwang-scoped, Governance NAV functions remain Governance-scoped, and LOC NAV functions use the integrated LOC Scope.
