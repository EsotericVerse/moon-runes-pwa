# NAV invariants

1. Exactly one NAV.
2. First entry is the governed reserved entry of the active Scope.
3. Context/statistics/culture/governance/search inherit the active Scope.
4. LunaRunes has equivalent `lrunes` and LOC `/runes` entry forms.
5. Management link appears only where the Current NAV contract specifies it.
6. Page-local menus are not NAV.
7. Draw history is not exposed in NAV.
