# NAV Scope route examples

- LOC `/context` → LOC integrated context.
- LOC `/runes/context` → LunaRunes context.
- `lrunes.lo3rwang.cc/context` → the same LunaRunes context as LOC `/runes/context`.
- `lo3rwang.cc/context` → lo3rwang Scope context.
- `manage.lo3rwang.cc` → highest-level management entry.

The same derivation applies to `statics`, `evolution`, `governance`, and `search`. These are shared functions; Scope determines the data and result. NAV is mutable Page Composition, so route examples follow the Current canonical Scope/host map rather than freezing an older route shape.
