# NAV release note

NAV resolves shared functions from the active Scope while governed Domain is authoritative before directory/path. LunaRunes uses `lrunes.lo3rwang.cc` as its canonical Domain, LOC uses `loc.lo3rwang.cc`, and path-only Scope inference is compatibility fallback only. Current terminology is one NAV only, with local menus kept separate. Scope registration is centralized and CI-guarded.
