# LOC｜Luna Codex

**LOC／月典 — Language Architecture Framework（語言架構框架）**

LOC 用於整理與探索作品、資訊和時間脈絡，提供搜尋、統計、文化時間軌跡與內容管理等功能。

**LunaRunes／月之符文 — Symbolic Language（符號式語言）**

LunaRunes 提供符文抽牌、每日符文、符文圖鑑與互動體驗。
