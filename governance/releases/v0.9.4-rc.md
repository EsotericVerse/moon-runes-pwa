# LOC 0.9.4-RC — Sitemap 導覽補強與 iOS IPA

**套件版本：** `0.9.4-rc`  
**iOS 原生版本：** `0.9.4 (6)`  
**日期：** 2026-10-11  
**性質：** Release Candidate，iPhone 實機 arm64 **未簽署** IPA  
**發版來源：** GitHub `main`；僅在版號一致、完整 CI、靜態輸出與原生封裝均成功後建立不可變的 prerelease。

## 本次變更

- **Sitemap 導覽總檢討：** 保留頂部非浮動 NAV 與固定六功能 Dock；深層的 `/statics/keywords/`、`/governance/manage/` 等頁面能正確保有父層功能歸屬，不另外發明第三種全域選單。
- **補齊子頁返回：** 符文抽牌、每日符文紀錄、圖鑑與詳細符文、3D 場域、符文遊戲，以及作者工作／其他介紹，使用父頁返回鍵；治理管理增加返回治理。
- **iOS 本機路由：** 符文首頁、抽牌模式、圖鑑分層、3D 三模式、一般 Scope／Scope Group 的內部連結依 Capacitor 或 Web 使用正確路徑；Native 404 回到封裝內 LOC 首頁，不開啟外部網站。
- **觸控補強：** 關鍵詞圖譜提供「編輯選取項目」與「重置視野」，保留原來的拖曳／雙擊及現成 vis-network 編輯器；時間長河既有左右、縮放、重置維持不變。
- **品質回歸：** 增加深層 Dock／返回鏈路測試，修正手機 Playwright 不該嘗試操控隱藏的統計控制項。

## 範圍不變

不更改 PostgreSQL / Supabase / Neon Schema、Scope 授權／RLS、Galaxy 資料、LunaRunes Canon、占卜規則與遊戲邏輯；不改原有 import workflow 或將私人本機檔案上傳伺服器。

## iOS 封裝與下載

- GitHub prerelease tag：`v0.9.4-rc`
- 產出檔案：`LOC-0.9.4-RC-unsigned.ipa`
- 組裝：Capacitor 8、Xcode 實體裝置 arm64 Release Build、Bundle ID `cc.lo3rwang.loc.mobile`
- 維持 LOC AppIcon、66 張符文卡 ASCII 路徑／檔名及 GitHub Actions 30 日 Artifact。
- **未簽署 IPA 無法直接安裝**：需在本機透過 AltStore 或其他支援的簽署工具完成簽署。請勿提供 Apple ID、簽章憑證或私人檔案給 CI。

## 驗收界線

GitHub Actions 成功代表程式測試、Next static export、iOS 裝置編譯與 IPA 封裝通過，不等同於已在 iPhone 17 Pro Max 實機驗證點擊、動態島、橫向佈局、登入與 SQLite 行為。私密 MSN 匯入功能及匯入真實資料安全性仍待獨立實機驗收。

在 GitHub prerelease 實際成立、附件確實上傳以前，本文件僅是發版規格，不代表 IPA 已產出。
