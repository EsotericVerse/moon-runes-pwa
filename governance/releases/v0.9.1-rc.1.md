# LOC 0.9.1-rc.1 — CSS／DIV 收斂候選版

**日期：** 2026-10-09  
**基線：** 0.9.0-rc.1 後的 Current main；實際候選版 commit 以 PR 合併後的驗證結果為準。

## Release scope

- 延續 0.9 的 Scope／Scope Group、Galaxy／Time／Keyword、LunaRunes、搜尋、文化、統計與治理功能，**不新增功能或資料表**。
- 首頁採 LOC／作者同一套 DB-backed `LocHomeBlockDisplay`；刪除未啟用的舊作者 Hero DOM 路徑。
- 刪除已退役的首頁 CSS、相依 RWD 覆寫與無效 class；保留現行 Hero 圖片、富文字、字重與手機排列方式。
- 新增 static contract 防止舊首頁樣式回歸，保留目前 43 個 DB Theme Token 與所有資料權威，不引入第二套 Theme。
- 補齊 Current package、lockfile、README、Packages、UI Contract、TODO 與 Roadmap 版本資訊。

## Evidence gate

- 候選版須通過 `npm run verify`、public DB probe、Next build/static export、Playwright browser checks。
- 真實畫面驗收與不同 iOS 裝置的人工確認另列於 `docs/TODO.md`；CI 成功不能替代使用者驗收。
- 本文件記錄候選版範圍，**不表示 prerelease Git tag 已建立**，也不宣稱 1.0 完成。
