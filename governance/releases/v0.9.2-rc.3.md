# LOC 0.9.2 RC3 — iOS App 與新版共用導覽

**版本：** `0.9.2-rc.3`（SemVer）  
**發版日期：** 2026-10-10  
**類型：** Release Candidate，非 1.0 正式版  
**來源：** 合併本版本 PR 後的 `main`；GitHub Release／IPA 只有在 CI 完成驗證與編譯後才建立。

## 本版納入

- **共用 NAV：** 上方第一列為非浮動的正常版面；左側收藏空間可水平滑動，內容溢出才顯示 `<<`／`>>`，右側保持「回月典首頁」。使用者可在「我的最愛」新增、命名、刪除目錄，展開時只增加第二列。NAV 左右留白對齊每頁實際內容框（LOC／作者首頁較窄，一般功能頁較寬）。
- **六鍵浮動功能選單：** 首頁、文化、統計、搜尋、治理、設定；每鍵獨立樣式、依 Scope Theme 顯示；設定為全域；保留 iOS 安全區。
- **LOC 文化：** 正式來源指定與時間／項目交會的現行程式，符韻資料型河道與真實月相；繼續依 `docs/TODO.md` 做人工資料驗收，不把待驗證的文化資料宣稱完成。
- **原生 iOS App Icon：** 使用此前確認的 LOC 圓形月球／時間長河／觀測點徽記，產生不透明 1024×1024 的 iOS AppIcon，取代 Capacitor 預設桌面圖示；此為 LOC App 原生圖示，不混用符韻或作者的圖示。
- **iOS IPA：** Capacitor 8 靜態資源與 66 張符文卡牌 ASCII 安全檔名，Bundle ID 保持 `cc.lo3rwang.loc.mobile`，原生版本為 `0.9.2 (3)`。CI 提供 `arm64` 實機 **unsigned IPA**，並在編譯產物中檢查 AppIcon 資源、版本、Bundle ID 及符文檔案。

## 下載與安裝說明

預期檔案：**`LOC-0.9.2-RC3-unsigned.ipa`**（GitHub pre-release Assets，待工作流程成功建立）。

這份 IPA **未簽署**，不能直接當作已安裝的簽署版使用。需經使用者自己的 AltStore／Apple ID 或適當的 Apple 開發者簽署方式簽署並安裝；CI 不保存 Apple ID、密碼或憑證。這次的 IPA 更新也不能取代 AltStore 的定期簽章刷新。

本版是安裝測試候選版；**不表示已通過 iPhone 實機人工驗收**。App 私密 Local File 的原生選檔／保留／離線搜尋尚未實作，MSN 對話紀錄也未作真實匯入驗收。匯入功能與其 DB round-trip 同樣維持 Pending。
