# LOC 0.9.2-rc.2 — Scope Admin 穩定修正版

**日期：** 2026-10-10  
**類型：** Release Candidate／現行 `main` 修 bug 定版  
**版本格式：** `0.9.2-rc.2`（npm SemVer prerelease；不是 `0.9.2.rc.2`）  
**基線：** 0.9.2-rc.1 後已合併至 Current `main` 的 Scope 管理、Theme／路由契約與治理修正；PR #491–#496。

## 納入範圍

- Admin Scope 關聯圖：vis-network 水平階層、全幅圖面與屬性摘要先行；Domain／Directory 清楚標示，管理者可依 Scope 規則編輯 `silver.manage.Title_TW`、`Desc_TW`（#491–#493）。
- Scope 建立：Supabase 動態六張資料表與 Rune66 獨立複製；`api.provision_scope` 在資料交易提交後主動通知 PostgREST schema reload；前端讀取加入有界重試並區分「建立已成功／快取尚未同步」（#494）。
- Scope 刪除：vis-network 與 Attr 面板使用同一頁內確認與 ID 比對；執行 `delete_scope` 後核對回應及 Registry 才移除圖面節點，取消或失敗時不偽裝成功（#495）。
- Scope 預設語系摘要與選項顯示統一為「繁體中文／简体中文／English」；DB 仍保留 BCP 47 標準代碼（#496）。
- 延續已合併的 Theme typed columns／numeric ID 1–8（#486），停止使用已被取代的 #485 舊方案。
- Branch 收整：GitHub 現存 31 個分支中 29 個為 Frozen，僅 `main` 與 `feat/ios-device-build` 維持 Active。Frozen 歷史記錄共 297 筆；不刪除原始歷史分支。iOS IPA 建置 #479 持續獨立開發。

## CI 與驗收邊界

- 管理合約／資料庫 API／靜態 Next.js 建置／瀏覽器測試需以 **RC2 對應 commit** 的 CI 為準；提交本版本文件不代表已自動通過。
- **Scope 核心管理功能已由使用者在正式站人工驗收，確認正常；這是決定發布 0.9.2 RC2 的前提。** 新增／刪除 Scope 與節點管理不再列為 Pending。跨裝置、其他權限邊界、實際 iPhone IPA 與私密本機資料驗證仍須另行確認。
- **Import：Pending／未用真實來源資料完整驗收。** 包含自訂 JSON、多檔預覽、批次寫入、錯誤恢復、資料 round-trip。
- 維持 `docs/TODO.md` 人工驗收清單；RC2 不等於 1.0 GA，亦未新增平行資料庫／管理模組。
