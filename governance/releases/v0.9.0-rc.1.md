# LOC 0.9.0-rc.1 — Release Candidate

**Date:** 2026-10-08  
**Classification:** Pre-release / candidate for hands-on acceptance  
**Source baseline:** `main` at `64ccad0b2bd4376fae1b41c882c7b55ca16433ad` before release metadata commit

## Included in this RC

- Scope Registry and Scope Group governance with `parent_scope_id` as the membership authority; Group Search / Statistics / Culture are overview-and-navigation views, **not** cross-Scope corpus aggregation.
- Shared generic `/scope/…/?scope=<id>` routes, data Scope mapping, copy-on-create provisioning, and independently editable UUID-addressed keyword classes.
- Current LOC Search, Statistics, Culture, Governance, Author and Admin/Manage functionality; Theme / Hero / Time and keyword editing use the merged Current implementations.
- Existing LunaRunes Rune Draw, Daily, Directory and Game flows remain separate from LOC's general-Scope semantics.
- No new application features, database schema changes, image storage, CSS special cases or Canon revisions in this release promotion.

## Automated gate

The release publishing job checks package and lockfile versions, installs from lockfile, runs repository contracts, public-DB verification, production static build and Playwright browser tests **before** creating tag `v0.9.0-rc.1` and its GitHub prerelease.

## Not yet manually accepted

- Desktop/mobile public navigation, Hero, Culture, Statistics, Search, Governance, Author, LunaRunes draw / directory / Game smoke tests in the live deployment.
- Management/Admin/Scope CRUD, permissions, read/write round trip and rich-text publishing/editing; Import with real data.
- Search/Culture/Statistics large-corpus load, pagination behavior, loading/empty/failure UX and cross-environment deployment regression.
- Daily Rune log new-record behavior is subject to its separate feature checklist.

Track unresolved items in [Current TODO](../../docs/TODO.md) and the [0.9 readiness review](../reviews/rc09-readiness-20261008.md).

**RC is not GA and is not evidence of completed manual acceptance.**
