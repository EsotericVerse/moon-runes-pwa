# LOC 0.9.2 RC3.1 — iOS Dynamic Island NAV 與符韻月相河道

**版本：** `0.9.2-rc.3.1`（SemVer）  
**原生版本：** `0.9.2 (4)`（iOS Build Number 4）  
**日期：** 2026-10-10  
**類型：** Release Candidate 3.1，未簽署 iOS 實機 IPA  
**來源：** GitHub `main`；僅在本版本發版 CI 完整通過後建立 immutable prerelease。

## 主要更新

- **PR #515 / iPhone Native NAV 避讓：** 原生 Capacitor WebView 宣告 `viewport-fit=cover`；依 iOS `safe-area-inset-top` 與可用尺寸避讓動態島。縮小上方「我的最愛」第一列垂直占用，不改普通網站版、Scope 連結、目錄第二列、固定六鍵 Dock 或 NAV 非浮動定位。此改動尚需 iPhone 17 Pro Max 實機直向與橫向檢查。
- **PR #514 / 符韻文化與 LOC 文化：** 真實月相不獨立存在。只有實際引用符韻每日符文且查詢期間包含可讀取的抽符紀錄時，才在同一日期軸上方附帶真實月相河道；月相變動日是事件錨點，延續到下一次變動，沒有抽符的中間日期不中斷；完全沒有每日符文則不顯示。未引用每日符文的一般 Galaxy/媒體河道不產生月相。符韻文化刪除重複的「查看每日符文行事曆及前次紀錄」連結。
- **版本／包裝：** Bundle ID 繼續 `cc.lo3rwang.loc.mobile`；保留 LOC 原生月亮徽記 AppIcon、Capacitor 靜態輸出、66 張符文卡 ASCII 路徑與不含簽名的 arm64 實機封裝。原生 build number 從 `3` 更新至 `4`。

**月相計算界線：** 當前月相延用臺灣農曆五段式日期規則（新月／上弦／滿月／下弦／空亡），是日級推算，**不是精確天文朔望時刻**；不覆寫資料庫每日符文記錄，也不新增 Galaxy 數據或 Scope 權限。
