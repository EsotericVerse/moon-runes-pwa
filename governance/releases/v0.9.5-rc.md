# LOC 0.9.5-RC — 2D／3D 符文整合、環境自動分流與 iOS IPA

**套件版本：** `0.9.5-rc`  
**iOS 原生版本：** `0.9.5 (7)`  
**日期：** 2026-10-13  
**性質：** Release Candidate，iOS arm64 **未簽署** IPA  
**來源：** GitHub `main`，以這份發版紀錄的提交啟動自動簽發流程。

## 本版功能

- **LunaRunes 三個統一入口：** 「符文抽牌」、「每日符文」、「符文圖鑑」各保留單一入口；每個入口內可自行切換 2D 原創美術與 3D 符文特效。避免首頁同時列出各自獨立的 2D／3D 入口。
- **相容既有網址：** 原 `/card3d/duel/`、`/card3d/daily/`、`/card3d/list/` 可繼續進入 3D 預設模式；`/card/duel/`、`/card/daily/`、`/card/list/` 是正式功能入口。
- **3D 舞台視覺：** 採用已驗收的原有 66 枚中文字型及縮小後的字體比例、最大 2.0 倍召喚放大、純黑舞台，以及原有 Effekseer 特效。2D／3D 內部表現與 66 枚符文定義保持各自原貌。
- **LOC 原始版面契約：** 使用 `loc-next-main` 外層加 `loc-panel` 文字框的既有排版，保留結果籤詩在深色視窗上的獨立可讀性。
- **匯入入口依執行環境自動分流：** 原生 iOS App 設定頁使用本機 Local File；網站版設定頁使用 Scope 授權的資料庫 JSON Import／Source Refresh（以 Supabase 為主要資料庫）。不依螢幕尺寸判定，也不需使用者選擇後端。手機 App Local File 目前是原始檔案儲存，**不是**等同網站端的結構化資料庫匯入。

## 封裝內容與驗證條件

- Capacitor 8、macOS Xcode、實機 `iphoneos` arm64 Release Build。
- Bundle ID：`cc.lo3rwang.loc.mobile`；MARKETING_VERSION `0.9.5`，CURRENT_PROJECT_VERSION `7`。
- 保留經批准的 LOC AppIcon、66 張符文卡的數字 ASCII 路徑與現有 iOS 本機路由。
- 執行 repository contracts、公開資料庫介面、靜態輸出及瀏覽器檢查；成功後才執行 Xcode、IPA 封裝和 GitHub prerelease 上傳。
- GitHub Release 標籤：`v0.9.5-rc`；檔案：`LOC-0.9.5-RC-unsigned.ipa`。
- GitHub Actions 同時提供 30 日有效的 unsigned IPA artifact。

## RC 驗證調整

- Playwright 設定功能下拉選單改為點擊 react-select 的可見控制項，而非會移出螢幕的內部 dummy input；維持原有 UI 和資料寫入邏輯不變。

## 重要限制與驗收界線

**IPA 為未簽署開發封裝，不能直接安裝到 iPhone**；需要使用者自己的合法 Apple 開發／個人簽署方法完成簽署，請勿提交 Apple ID 或憑證到 CI。

GitHub CI 成功僅確認程式契約、靜態網頁輸出、iOS 編譯及 IPA 結構，不代表真實 iPhone 的點擊、登入、SQLite 或匯入流程已完成實機驗收。JSON／Source Refresh 和本機匯入的實際備份檔讀寫、失敗復原、重複匯入仍需要端到端驗收。

本檔案是**發版指令與規格**，並非表示 IPA 已經生成。只有 GitHub Release 實際出現且 IPA asset 可見時，才視為打包成功。
