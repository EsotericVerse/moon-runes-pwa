## Domain boundary

- LunaRunes home: `https://lrunes.lo3rwang.cc`
- Vocabulary / Rune Atlas: `https://lrunes.lo3rwang.cc/list`
- LOC home: `https://loc.lo3rwang.cc`
- Manager home: `https://lo3rwang.lo3rwang.cc`

Domain determines Scope before directory/path.

## Homepage media rule

The LunaRunes homepage contains exactly one embedded Reel iframe: the LunaRunes introduction/explanation Reel.

Divination or draw-demo Reels are links only on the homepage. They must not be embedded as additional homepage iframes. Their full presentation belongs to the appropriate example/demo destination.

This is a Page Composition rule, not a media deletion rule.
