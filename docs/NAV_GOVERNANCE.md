# LOC 導覽治理原則

**Status:** Current
**Updated:** 2026-09-16

## 單一 NAV

每個介面只有一條正式導覽列（NAV）。頁內目錄、本地功能入口、返回連結、架構圖與快捷選單可以存在，但不是第二或第三套 NAV；Current 文件與程式不得再使用 NAV2／NAV3 名稱。

## Scope 可治理文字

導覽的功能責任與目的地應保持清楚，顯示文字則可由所屬 Scope 管理。個人首頁第一個導覽文字可由個人 Scope 管理者修改；設定只對該個人首頁／instance 生效，不改寫 LOC 或 LunaRunes 的全域名稱。

修改導覽文字時必須保留：

- 唯一且可理解的目的地；
- 變更前後值、操作者、時間與理由；
- 無障礙可辨識名稱；
- Scope 邊界，不把個人名稱冒充全域 Canon。

## 本地入口

個人、LunaRunes、治理及其他 Scope 可以提供自己的頁內功能入口與「返回首頁」。這些入口協助使用，不建立另一條正式 NAV，也不改變資料歸屬或管理權。
