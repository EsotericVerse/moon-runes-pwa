# LOC Automatic Analysis — Current Concept

## Fixed identities

- **LunaRunes — Symbolic Language**
- **LOC — Language Architecture Framework**
- **Lucas Oscar Wang — Language Architect｜語言建築師**

「語言建築師」是正式職稱。其他如文字建築師、文化拆解者、文化校對者、符文建築師可作自我描述，但不取代正式職稱。

## Core principle

LOC 的重點不是只顯示資料，而是：

**觀察 → 統計 → 比較 → 機械判斷 → 自動建議 → 人類決定**

系統必須主動協助使用者看見軌跡，而不是要求使用者先自己猜一個時間點再查資料。

自動分析可以判斷「資料發生了什麼變化」，但不能替使用者判斷「這段人生／文化的意義是什麼」。

## LunaRunes Daily — smallest symbolic implementation

每日符文是 LOC 最小型、最容易理解的 Symbolic Language 實作。

Daily 的主要視覺是 **Calendar／行事曆**，不是 Time River。

分析入口：

1. 單體每日：既有每日符文。
2. 今天＋明天。
3. 昨天＋今天＋明天。
4. 近七天。
5. 自訂日期區間解析。

區間分析同時觀察：

- 正抽／補抽。
- 符文出現頻率與密度。
- 同一符文是否跨日重複。
- 同一符文的位向是否改變。
- 四向分布。
- 自動中立建議。

兩個最重要的提醒：

- **高頻提醒**：某符文在區間內反覆、大量出現，提示使用者留意該主題是否持續出現。
- **位向變化提醒**：同一符文在區間內出現不同方向，提示使用者回看前後紀錄。

這些提醒不是吉凶裁決，也不是抽牌牌陣的因果演算法。

## Culture / Time River — spacetime anchoring

Culture 的 Time River 負責大型時間分布。

**時空定錨論**在系統中的責任：

- 先依作品／發文時間形成密度分布。
- 比較前後區間。
- 找出明顯密度增加、下降或重新出現的候選位置。
- 自動提示「這段時間是否有值得標記的事情」。
- 可以直接 Search 該時間附近的文字與作品。
- 可以把建議日期帶入 Anchor 設定。
- **Anchor 永遠由使用者確認後建立；系統不得自動替使用者定錨。**

建議語氣以可觀察事實為主，例如：

> 這段時間你的發文數量特別多，是有發生什麼值得標記的事情呢？

「標記」不代表好、不代表壞，也不代表一定是人生轉折。

## Statistics / Style / Keywords — oscillation

Statistics 的側重不是時間位置，而是語言分布。

**靈魂擺盪論**在系統中的責任：

- 大風格分布。
- 風格標籤分布。
- 關鍵詞分布。
- 增加、減少、延續、消退、回返與擺盪。
- 集中度與低頻長尾。
- 找出可提高、降低、新增或淘汰的關鍵詞候選。

第一階段先產生可解釋候選，不直接改寫詞庫；後續自動治理必須仍可追溯到統計與時間資料。

## 4D relation

Time River 與 Statistics 的側重不同，但可以在 4D Graph 中交會：

**時間區間 ↔ 發文密度 ↔ 大風格 ↔ 風格 ↔ 關鍵詞 ↔ 來源／作品／關係**

- Culture 回答：**什麼時間發生變化？**
- Statistics 回答：**哪些語言／風格分布在變？**
- Search 回答：**當時實際寫了什麼？**
- Context / Graph 回答：**哪些資料彼此相關？**
- Human Governance 回答：**這些變化對使用者而言代表什麼？**

## Scale

相同方法可以從小到大使用：

- 個人風格。
- 個人文化。
- 組織文化。
- 社群／群體文化。
- 社會文化。
- 歷史文化。

LOC 以歷史資料驗證，以工程方法機械解析，以統計觀察文化變化。可重現的分析與來源資料優先於主觀敘事。

## IP and neutrality

LunaRunes 是作者重要個人 IP，也是符號式語言的代表實作。

LOC 是一般化的機械工具框架，可以處理其他人的文字、組織資料與歷史資料。

因此三者關係固定為：

- **LunaRunes：文字／符號體系。**
- **LOC：機械分析工具與架構框架。**
- **Language Architect：建構、拆解與校對這套系統的人。**

系統可以有作者特色與 IP，但分析層必須保持可解釋、可追溯、中立、不裁決。
