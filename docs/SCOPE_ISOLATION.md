# Scope Isolation — Current

## Highest principle

Scope isolation follows data ownership.

- Shared functions do not imply shared content.
- Each Scope owns its vocabulary, context, statistics, culture, governance and search results.
- Integration does not transfer ownership.
- A work Scope does not inherit another work Scope's vocabulary, content or governance.
- The Author Scope may include the author's works because those works are author-owned data. This is an ownership relationship, not permission for work Scopes to inherit from one another.

## Current ownership

- 月典 Scope: 月典-owned integrated data only.
- 月之符文 Scope: 月之符文-owned data only.
- 作者 Scope: author-owned data, including the author's own works such as 月典 and 月之符文.

## Governance isolation

`/governance` is a shared function route, not a shared dataset. 月典治理 and 月之符文治理 are independent and must not reuse each other's keywords or governance content.

## Route invariant

`lrunes.lo3rwang.cc/{route}` and `loc.lo3rwang.cc/runes/{route}` are two entry forms for the same 月之符文 Scope. They must resolve to the same Scope-owned function/data.

## Public copy boundary

On the 月之符文 homepage, LOC/月典 may appear only in the explicit return-to-月典 navigation entry. It must not be used as homepage copy, metadata branding, explanation or governance content.
