# OW3gs｜Naming Lineage / Current

狀態：Current KM／命名權威補充  
更新：2026-09-16  
作者：Lucas Oscar Wang 政德

> 本文件先固定 OW3gs 的名稱、類型與歷史沿革，避免後續 Canon／KM 整併時由現行名稱反向重寫歷史。若其他 Current 文件與本文件的 OW3gs 命名或類型衝突，以本文件為準，待主 Canon 整併時吸收。

## 1. Current 類型

**OW3gs 是 Model／模型，不是 Module／模組。**

OW3gs 可以被模組化實作，也可以被 LunaRunes、Search、KM、歌曲、文學與其他延伸體系調用；但「可被模組化實作」不得改寫 OW3gs 本體的類型。

Current 標準描述：

**OW3gs — 11-card comprehensive scenario model／11 張綜合情景模型。**

因此舊 Current 文件中的「OW3gs 模組」「11 張綜合情景模組」等本體分類視為待遷移用語；Historical 原文可保留，但不得繼續作為 Current 類型。

## 2. 原始名稱

OW3gs 的原始正式名稱為：

**Oscar Wang 3 Grounds System**

OW3gs 是歷史原名，早於作者後來採用 `lo3rwang` 與「政德」作為 Current 公開識別。後來的身份與框架不得反向改寫 OW3gs 的原名。

## 3. Oscillation 名稱層

OW3gs 的名稱脈絡亦加入：

**Oscar Wang Oscillation 3 Ground System**

其中 **of 不顯示於名稱字面**。不得為了英文展開或重新造 acronym，擅自把未顯示的 `of` 加入正式顯示名稱。

此名稱層與 **Oscar Wang 3 Grounds System** 一併保存為 OW3gs 的命名沿革；後續若整理字源、縮寫或顯示名稱，必須保留兩者的歷史關係，不得用後來的 backronym 取代。

## 4. Grounds 演進

Grounds 的歷史／方法演進固定為：

1. **1G = Context**
2. **2G = Culture**
3. **3G = OW3gs**
4. **4G = lo3rwang**

這條 Ground lineage 是名稱與方法演進，不等於 OW3gs 11 張牌的內部位置結構，也不得被重新解釋成三段、三張、三個抽牌區塊或其他牌陣結構。

## 5. lo3rwang 與 LOW 的邊界

`lo3rwang` 是後來形成的作者公開識別，與 Ground lineage 有歷史關係，但：

- **`lo3rwang` 不等於 `LOW`。**
- **OW3gs 不得寫成 LOW3GS。**
- 不得把 `lo3rwang`、OW3gs 或 Ground lineage 解釋成英文 `low`（低、低階等）的語意。
- 作者刻意不採 `LOW` 作為統一縮寫，以避免英文 `low` 帶來錯誤語意與語感。

## 6. 與 OW3gs 11-card 結構的區隔

Ground lineage：

`1G Context → 2G Culture → 3G OW3gs → 4G lo3rwang`

OW3gs Current 模型結構則是另一層：

`OW3gs Model → 11-card comprehensive scenario → 1–6 Context 描述層 + 7–11 核心判定層`

兩者有歷史與方法關係，但不可互相代換。尤其不得把 `3 Grounds` 反向解釋成 11 張牌內部的三個 Ground。

## 7. Canon / KM 遷移規則

後續整併 Canon 與 KM 時：

- Current 一律把 OW3gs 本體分類為 **Model／模型**。
- 保留 **Oscar Wang 3 Grounds System** 原名。
- 保留 **Oscar Wang Oscillation 3 Ground System** 名稱層，且 `of` 不顯示。
- 保留 `1G Context → 2G Culture → 3G OW3gs → 4G lo3rwang` lineage。
- 保留 `lo3rwang ≠ LOW` 的命名邊界。
- 舊文件若稱 OW3gs 為 Module，應做 Current semantic migration；Historical 原文不必抹除。
- 新的 Current 解釋可以增加脈絡，但不得用後來的 LOC、政德、lo3rwang 或其他名稱重寫 OW3gs 的歷史名稱。
