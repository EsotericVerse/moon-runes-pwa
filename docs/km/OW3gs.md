# OW3gs

## Current definition

OW3gs 是 LunaRunes 的 **11-card comprehensive scenario model／11 卡綜合情景模型**。

它是 LunaRunes 的特殊模型，不是一般 LOC Scope 的預設架構，也不是 LunaRunes Game 規則。

## Structure

OW3gs 一次抽 11 張，不重複 Rune。

Current sentence structure：

**因為（因為 1、2，變數 3、4，所以 5、6），所以（因為 7、8，變數 9，所以 10、11）。**

Responsibilities：

- 1–6：因的描述層。
  - 1–2：源
  - 3–4：轉
  - 5–6：合
- 7–11：核心判定層。
  - 7–8：過去成因
  - 9：意外變化
  - 10–11：現在狀況／結果

7–11 是核心判定；1–6 補足造成現況的背景、條件與變化。最終輸出必須綜合兩層，不把 11 張當成等權單卡相加。

## Draw rule

- 11 張屬同一 Draw Session。
- 每張 Rune 逐次 random。
- 抽出後從當次候選池移除。
- direction random 與 Rune selection 分離。
- 第零符 德不進抽取池。

## Reading rule

OW3gs 不使用數值權重、平均分數或機率分數取代 Grammar。

每張只使用實際抽到的 direction data。真實月相最後才加入，只作次要時間情境修飾，不覆蓋 Rune meaning、direction 或 11-card structure。

## Relationship to LOC

LOC 可以保存 OW3gs 的 draw record、作品 relation、Search result、Culture time position 與 Statistics distribution；這些 LOC 功能不改寫 OW3gs Grammar。

OW3gs 只在 LunaRunes 需要時使用，不作為一般 Scope 缺值時的 fallback。
