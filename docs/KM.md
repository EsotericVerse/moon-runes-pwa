# LOC Knowledge Management

## Status

KM 重新啟用為 **Current knowledge layer**。

KM 用來保存可重複使用的方法說明、操作模型與已確認的知識整理；它不是 Canon、不是 Neon SSOT，也不是 runtime fallback。

## Authority

當 KM 與 Current implementation 衝突：

1. 使用者當下明確規格
2. Current main + Current Neon
3. LOC Current Canon
4. Current KM

LunaRunes 的 Rune canonical meaning 另以 LunaRunes canonical source／tables 為準。

## Current-only rule

KM 不保留已被 Current 取代的概念、lineage、舊全名、舊分類或相容說法。需要理解歷史時使用 Git history，不在 Current KM 放第二份舊定義。

## Scope rule

- LOC KM 可以描述框架方法。
- LunaRunes KM 可以描述 Rune-specific method。
- Rune special semantics 不提升為一般 Scope default。
- KM 不得創造 table、route、keyword fallback、permission 或 runtime authority。

## Location

Current KM files 放在 docs/km/。
