# LOC6 政德風 — Zhengde Style Governance

**Status:** Current / Working Structure  
**Owner:** LOC6  
**Updated:** 2026-09-05

## 1. 定位

政德風不是單純的「文筆風格」或語錄合集，而是作者長期把經驗、價值判斷、界線、決策方式與表達習慣整理成可重用語言後形成的個人語言治理 corpus。

目前 LOC6 可同時承接兩種不同但相關的資料：

1. **符文文法／牌組語意**：符文組合、方向、關係與牌組如何形成語意。
2. **政德風治理 corpus**：作者如何把價值、界線、判斷與人生階段說成穩定可辨識的語言。

兩者不可混成同一資料集，但都屬於 LOC6 對「語言如何形成可判斷結構」的實際材料。

## 2. 政德風核心公式

> **把經驗整理成可以再次使用的語言。**

目前 repo 已反覆出現的核心可以收斂為：

```text
看見情境
→ 拆解預設
→ 確認權責
→ 建立界線
→ 保留選擇
→ 做出取捨
→ 回到可治理的日常
```

這比「反抗」更接近現在的政德風。2026 年後的重心已逐漸從拆解外部劇本，移到 **治理自己、完成收尾、選擇航向**。

## 3. 核心治理模組

### 3.1 價值與判準

用自己的價值標準判斷事情，而不是因為權威、群體或既有劇本就直接接受。

已存在代表句：

- 「價值觀的價值。」
- 「我允許錯誤發生，只要錯的有價值。」
- 「免錢的最貴。」

### 3.2 主權與選擇

保留回答、拒絕、失敗、修改與重新決定的權利。

已存在代表句：

- 「我不跟你走劇本。」
- 「你在玩話術，我在改規則。」
- 「我不是要當王，我只要系統能跑。」

### 3.3 權責與界線

先確認「這件事是不是我的位置、責任與義務」，再決定是否介入。

2026「治理自己」ERA 已明確出現：

- 確認位置與責任
- 建立界線
- 停止勉強維繫
- 清點未竟事項
- 完成承諾
- 斷捨離與重新歸檔

### 3.4 防衛而不失控

政德風的防衛不是無限制對抗，而是在必要時停止被侵入、被定義或被拖進不屬於自己的責任。

已存在代表句：

- 「慈悲不是投降。」

### 3.5 幽默與反轉

以短句、反問、雙關或現實落差拆掉話術，避免被對方的敘事框架綁住。

這類句型的功能不是追求機智，而是快速重設語境。

## 4. 2026 現行階段：治理自己

現行 ERA 的關鍵不是「得到自由」本身，而是 **自由之後如何治理自由**。

目前 LOC3 已有明確作品證據：

- 《白晝也有月光》：確認位置與責任、建立界線、停止內耗、自我照亮。
- 《清空舊航線》：清點未竟之事、完成承諾、斷捨離、重新歸檔、選擇新航向。

因此 2026 現行政德風可概括為：

> **從「拆別人的劇本」逐漸移向「治理自己的日子」。**

這不是舊風格消失，而是治理重心從外部防衛轉向內部秩序與未來選擇。

## 5. 風格層與治理層分開

政德風至少需要分成兩種資料：

### Governance Content
回答「相信什麼、怎麼判斷、界線在哪裡」。

例如：
- 價值判準
- 主權
- 權責
- 尊重
- 界線
- 自我治理
- 收尾與航向

### Style State
回答「同一個意思，在某個時期會怎麼說」。

例如：
- 句子長短
- 感性／理性比例
- 意象密度
- 反問與反轉
- 攻擊性／克制度
- 是否偏向外部拆解或內部治理

兩者不能混為一談：價值可能延續，但說法會隨人生階段演變。

## 6. 時期投影模型

未來要做到「30 歲的政德會怎麼說／46 歲的政德會怎麼說」，應以真實歷史文字建立 **Stage Profile**，而不是由 AI 猜一個年齡人格。

建議資料欄位：

```json
{
  "stage_id": "ZS-...",
  "time_range": "",
  "age_range": "",
  "source_refs": [],
  "governance_focus": [],
  "style_features": {
    "sentence_length": "",
    "imagery_density": "",
    "emotional_distance": "",
    "directness": "",
    "boundary_strength": "",
    "humor": ""
  },
  "representative_statements": [],
  "status": "recorded | reconstructed | proposed"
}
```

只有找到足夠歷史原文後，才建立 recorded profile。

## 7. 與其他 LOC 的關係

- **LOC3**：歌曲保存政德風在不同 ERA 的情緒與治理表達。
- **LOC4**：文章、小說、散文保存長篇文字與敘事表達。
- **LOC6**：保存治理原則、代表句、風格狀態與階段比較。
- **LOC7**：分析句法、結構、向量特徵與可檢索關係。
- **LOC8**：保存時期、事件與人生軌跡，使風格演變可以被時間化。

## 8. 治理規則

1. 原始語句保留原文，不以後期說法覆寫。
2. 「代表句」與「後設解讀」分欄保存。
3. AI 重寫不能冒充歷史原文。
4. 風格推論要保留來源與 confidence。
5. 不因某一句很像政德風，就自動升格為核心原則。
6. 現行階段可以更新，但歷史階段不得被新版本抹除。

---

**政德風的目標不是模仿一種語氣，而是保存一個人如何逐步形成自己的判斷與說話方式。**
