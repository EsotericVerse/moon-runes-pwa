# Luna Codex 66 — Governance Design Notes

**Version:** 0.1  
**Status:** Working Design Interpretation  
**System:** Luna Codex / 月之符文  
**Updated:** 2026-09-07

## 1. 定位

Luna Codex 66 的成熟度不只來自「66 個符文已固定」，也來自它能同時描述自我、關係、生命、自然、物質、元素、秩序與無序，並保留邊界、演化與自我治理能力。

月之符文的使用定位是籤詩／抽籤語言工具，不主張符文本身具有神秘力量，也不要求宗教、階級、師承或特殊身分。

> **符文提供語言，不提供權威。**

## 2. Equal Access — 平等使用

- 不因職業、地位、階級、信仰或其他身分改變基本符義。
- 不存在天然擁有更高解釋權的使用者。
- 使用者可以不同意某個解讀。
- 最終判斷權保留給使用者，不由抽籤結果取代。

其設計方向與 LOC 的中立治理一致：分享方法與語言，不要求服從某種世界觀。

## 3. 66 版的結構成熟

現行核心為八組 × 八符文＝64，再加 65 玄與 66 命。66 版的重要意義不只是數量增加，而是語義責任分割更完整。

### 3.1 靈魂組與連結組拆分

早期「靈魂連結」在 66 版拆成靈魂與連結，使「自我內部狀態」與「自我和他者／世界的關係」成為不同責任域。

### 3.2 界 / 域 — 邊界與領域

- **界**：分界、交界、接觸面與到哪裡為止。
- **域**：主體所處、負責、可以活動與治理的領域。

治理含義是先辨認自己的域與他人的域，再確認交界、協商，必要時重新畫界。

### 3.3 礦物組 — 價值與物質現實

礦物組使符文不只描述精神／情緒，也能描述價值、資源、物質條件、擁有、稀缺、交換與現實承載。這使人生治理可以回到現實條件，而不是只停在抽象精神層。

### 3.4 悟 — 理解後的演化

連結組中的「悟」可以描述「理解 → 重新看見關係 → 修正 → 形成新的適應方式」。它提供演化可能，而不是固定命令。

## 4. Evolution with Governance

Luna Codex 的符文位置與核心框架可以固定，但使用者的理解、relation、context 與人生版本可以持續演化。

> **允許變化，但不失去結構。**

穩定 schema 提供邊界；新理解透過 context、relation、version 與 history 被記錄。

## 5. Self-Governance, not Rule by Divination

抽籤結果是語言輸入，不是命令。流程是 Random draw → governed rune meaning → orientation / combination / context → interpretation → user reflection → user decision。

因此符文可以用於自我回顧與治理，但不能取代人的自主判斷。

## 6. Non-mystical Governance Position

月之符文保留「符文」「抽籤」「籤詩」等形式，但系統本身不需要假定超自然力量、神授解讀權、身分特權、絕對預言或單一不可反駁答案。

它是一套穩定的語義單元與組合規則，用於描述狀態、關係、變化、邊界、價值與可能性。

## 7. 成熟度判準

1. **Semantic maturity**：固定位置、核心定義與四向語意。
2. **Structural maturity**：八組、抽取、雙卡／三卡／五卡／OW3gs 等組合規則。
3. **Application maturity**：已被 LOC 的多個責任域實際引用。
4. **Governance maturity**：平等使用、中立描述、域與界、現實價值、演化、自我治理與使用者最終決策權。

66 版的成熟不是「已經給出永恆答案」，而是它已經能在穩定規則內容納變化。

---

**Luna Codex 66 principle:** a stable symbolic language that can describe reality, evolve through understanding, and remain governable without becoming an authority over the user.
