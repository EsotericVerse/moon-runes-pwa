# LunaRunes 66 — Governance Design Notes

**Version:** 0.2  
**Status:** Current Design Interpretation  
**System:** LunaRunes / 月之符文  
**Updated:** 2026-09-07

## 1. 定位

LunaRunes 66 的成熟度不只來自「66 個符文已固定」，也來自它能同時描述自我、關係、生命、自然、物質、元素、秩序與無序，並保留邊界、演化與自我治理能力。

月之符文是籤詩／抽籤語言工具與 Reference Seed System，不主張符文本身具有神秘力量，也不要求宗教、階級、師承或特殊身分。

> **符文提供語言，不提供權威。**

抽籤提供入口，Canon 維持語義邊界，真正的解讀仍需回到 context。

## 2. Equal Access — 平等使用

- 不因職業、地位、階級、信仰或其他身分改變基本符義。
- 不存在天然擁有更高解釋權的使用者。
- 使用者可以不同意某個解讀。
- 最終判斷權保留給使用者，不由抽籤結果取代。
- 醫療、法律、工作、合約、金錢與他人意願等現實事項，以現實證據與現實程序為優先。

其設計方向與 LOC 中立治理一致：分享方法與語言，不要求服從某種世界觀。

## 3. 66 版的結構成熟

現行核心為八組 × 八符文＝64，再加 65 玄（Chaos）與 66 命（Fate）。第 0 符「德」作系統基準，不參與實際抽牌。

66 版的重要意義不只是數量增加，而是語義責任分割更完整。

### 3.1 靈魂組與連結組拆分

早期「靈魂連結」在 66 版拆成靈魂與連結，使：

- 自我內部狀態
- 自我與他者／世界的關係

成為不同責任域。

這是 governance-oriented semantic separation：先知道「我是什麼狀態」，再描述「我如何與其他節點建立關係」。

### 3.2 界 / 域 — 邊界與領域

66 版靈魂組納入「界」「域」，補足自我治理需要的 boundary / domain language。

- **界**：分界、交界、接觸面與到哪裡為止。
- **域**：主體所處、負責、可以活動與治理的領域。

其治理語義是：

~~~text
辨認自己的域
→ 辨認他人的域
→ 確認交界
→ 在交界協商
→ 必要時重新畫界
~~~

這比固定的「底線」模型更接近現行設計：規則可以因 context 改變，但 domain boundary 必須可辨識。

### 3.3 礦物組 — 價值與物質現實

66 版加入完整礦物組，使符文不只描述精神、情緒與自然，也能描述：

- 價值
- 資源
- 物質條件
- 擁有
- 稀缺
- 交換
- 現實承載

其設計意義是把人生治理放回現實生活，而不是只停在精神或象徵層。

### 3.4 悟 — 理解後的演化

連結組中的「悟」可描述：

~~~text
理解
→ 重新看見關係
→ 修正
→ 形成新的適應方式
~~~

它不是「得到固定答案」，而是把理解之後仍可進化的可能性正式放入符文語彙。

## 4. Governed Evolution — 有邊界的演化

Luna Codex 的符文身份、位置、核心語義與組別可以固定，但使用者的 interpretation、relation、context 與人生版本可以持續演化。

~~~text
Stable Rune Framework
        +
Mutable Context / Relation / Interpretation
        ↓
Governed Evolution
~~~

> **允許變化，但不失去結構。**

演化不是任意改寫 Canon；新理解應透過 context、relation、version、evidence 與 history 被記錄。

## 5. Self-Governance, not Rule by Divination

抽籤結果是語言輸入，不是命令：

~~~text
Random draw
↓
governed rune meaning
↓
orientation / combination / context
↓
interpretation
↓
user reflection
↓
user decision
~~~

因此月之符文可用於自我回顧與自我治理，但不能取代人的自主判斷。

## 6. Non-mystical Governance Position

月之符文可以保留「符文」「抽籤」「籤詩」等文化與創作形式，但系統本身不需要假定：

- 超自然力量
- 神授解讀權
- 身分特權
- 絕對預言
- 單一不可反駁答案

它是一套穩定語義單元與組合規則，用於描述狀態、關係、變化、邊界、價值與可能性。

## 7. Why 66 is Mature

LunaRunes 66 的成熟可分四層：

1. **Semantic maturity**：固定位置、核心定義、組別與四向語意。
2. **Structural maturity**：八組、抽取、雙卡因果、三卡源－轉－合、五卡與 OW3gs 等組合規則。
3. **Application maturity**：已有抽牌、小說、歌曲、遊戲、Search、Relation、ERA 與跨 LOC 使用證據。
4. **Governance maturity**：平等使用、中立描述、界／域、物質價值、演化、自我治理、使用者最終決策權。

其成熟不是「已經給出永恆答案」，而是：

> **它已經有足夠穩定的規則，可以安全容納新的理解。**

## 8. Rune Governance Boundary

母資料與核心 identity 仍以 LunaRune64.xlsx 為最高優先來源。

生成模型、Search、RAG、Graph 或任何衍生應用：

- 可以解讀
- 可以建立候選 relation
- 可以提供比較與趨勢
- 可以生成衍生文字

但不得任意改寫符文 identity、固定位置、核心欄位或 Canon 母資料。

## 9. 與 LOC Governance 的關係

LunaRunes 66 是 LOC 最成熟的 Reference Seed System，也是 LOC 治理思想最早能被具體看到的地方之一：

- 「界／域」提供 boundary language。
- 礦物組提供價值與現實語言。
- 「悟」提供 evolution language。
- 固定 66 結構提供 stable framework。
- interpretation / context 的可變性提供 governed evolution。

因此它不是用來統治使用者，而是用來幫助使用者描述世界，再由 LOC 保存、比較與治理這些描述。

---

**LunaRunes 66 principle:** a stable symbolic language that can describe reality, evolve through understanding, and remain governable without becoming an authority over the user.
