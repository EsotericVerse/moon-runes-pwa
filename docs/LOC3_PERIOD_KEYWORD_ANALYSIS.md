# LOC3 時期關鍵字分析 v0.3

## 分析原則

LOC3 時期分析現在分成兩層：

1. **命名關鍵字**：微月光、人生月台、自我治理（治理自己）、已讀不回等專有／系列／跨 LOC 概念。
2. **語義關鍵字**：平靜、風、道路旅途、界線、未知探索、微光意象等作品內容詞。

> 命名概念不能被一般高頻詞取代。`微月光` 與 `微光意象` 是兩個不同維度。

## 治理

- `微月光`：LOC3 專有名詞；不與 `微光意象` 合併。
- `人生月台`：命名創作概念／系列詞。
- `自我治理`：canonical；`治理自己` 是 alias / 創作階段用語。
- `已讀不回`：跨 LOC3/4/5 的命名概念；LOC3 端只統計歌曲／歌詞證據。
