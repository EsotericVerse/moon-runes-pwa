## 定位

這份分析的主要目的不是替歌曲再加一組 ERA 名稱，而是把 LOC3 既有作品放回 LOC8 已確定的連續時期，觀察語言、主題、轉折與狀態如何隨時間改變。

> 時期是時間脈絡；關鍵字是作品語義。兩者分開治理。

現行分析來源為 LOC3 Lyrics Search 0.1.9，共 403 個可搜尋 unique lyrics works；依現行 corpus policy，P1 不納入正式關鍵字分析。

## 第一階段觀察

- P2–P3：微光、夜晚、月光、關係、孤獨與希望是主要語彙。
- P4：現實選擇、正義界線、守護界線與治理顯著提高，形成治理轉折。
- P5：風、道路、等待、未知與希望集中，對應人生月台的觀望／重建。
- P6：等待仍存在，但自由自主與共鳴／同行提高，語言開始由等待轉向整合。
- P7：自由自主、風、月光與界線集中；結尾狀態以自由／解放為最高。
- P8：目前樣本只有 2 首，不做高置信度趨勢宣稱；已出現自我治理、收尾、責任、航向、未竟之事等新詞。

以上觀察只依現有 metadata/tag 計數，不把未標註內容推定為不存在。P8 將隨新作品持續更新。

## 後續分析用途

1. 比較相鄰時期關鍵字的新增、消退與持續。
2. 將 theme / affect / action / imagery / governance 等詞彙拆成受控詞彙層。
3. 建立 period × keyword 的 normalized frequency，避免不同時期作品量差異造成誤判。
4. 把結果提供給 Unified Search 與 LOC8 時期脈絡視圖，但不改寫歌曲原始 metadata。
