# LOC2 — Semantic Playground
## MVP v1.3 Alpha

LOC2 是以 Luna Codex 符文為基底的語意互動卡牌原型。

它不是傳統攻擊／防禦型卡牌遊戲。核心概念是：

> 世界提出問題 → 玩家用符文回答 → 答案彼此共振或干預 → 形成暫時定義。

## 現階段定位

- 類型：事件解謎 + 玩家互動
- 核心數值：德（De）
- 勝利條件：德達 16
- 牌庫：每位玩家各自持有一套 1–64 符文牌，不共用
- 第 0 符「德」作為系統基準，不列入一般抽牌
- 65「玄」與 66「命」屬特殊符文；實際遊戲規則仍依版本測試調整

## 核心玩法

1. **事件出題**  
   世界／事件卡提出需要解決的問題。

2. **玩家回應**  
   玩家以符文組合回答事件，而不是單純比較數值大小。

3. **語意互動**  
   雙卡可形成因果、對照或互動；三卡可形成「源－轉－合」結構。更高張數的規則仍持續測試。

4. **共振與干預**  
   玩家之間可以讓答案彼此加強、偏移、衝突或重組。

5. **暫時定義**  
   一輪遊戲形成的是「此刻成立的語意結果」，不是永久唯一的標準答案。

## 已確立方向

### 16★
代表本輪達到暫時高度自洽的狀態。

### 0′
作為清空本輪定義／重新開始語意構築的特殊概念。

### 八職業
八職業不是能力值或人格分類，而是世界失序時的八種回應方式。現階段以核心職能、介入姿態與限定介入方式描述。

### 事件卡
目前已有 Alpha 事件卡範例，包含記憶、自我懷疑、真實表達、內在映照、誤解、合作、切斷、重建關係等事件方向。

## 與 LOC1 的關係

LOC1 的符文主要被「抽出與閱讀」；LOC2 則把同一套符文放進規則與玩家互動裡，讓符文可以被操作、組合、干預與重新定義。

因此 LOC2 可視為 Luna Codex 從抽籤系統走向可玩的語意系統的第一個應用延伸。
